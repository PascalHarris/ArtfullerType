# DodgerType

A distraction-free Markdown writing app for classic Macintosh computers.

DodgerType is a small, focused writing tool. It hides Markdown syntax while you write, showing styled text instead — headings, bold, italic, and more — while keeping your file as plain, portable `.md` text underneath. Switch to Markdown view any time to see or edit the raw source directly.

## What it does

### Writing

Type normally, and Markdown syntax like `**bold**` or `# a heading` converts to styled text as you go. Switch to Markdown view from the View menu to see or edit the plain source instead, with optional syntax coloring.

### Formatting

Bold, italic, underline, and inline code are all supported, along with six levels of heading. Blockquotes work too, including formatting inside them. Fenced code blocks render in a fixed-width font, with their contents always left exactly as typed. Links use the familiar `[text](url)` form.

### Files and printing

Documents save as plain `.md` text, readable in any text editor on any computer. Printing is fully supported, with correct pagination across multiple pages.

### Preferences

A plain-text preferences file controls default view mode, zoom level, the Markdown-mode font, and more. It's a normal text file, editable directly if you'd rather not use the Preferences window.

## System requirements

Any Macintosh capable of running System 6.0.8 or newer.
